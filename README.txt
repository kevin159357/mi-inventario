MI INVENTARIO
=============

Inicio rápido
-------------
1. Mantén la estructura de carpetas tal como está.
2. Abre index.html con Google Chrome o Microsoft Edge.
3. Contraseña inicial del administrador: 1234
4. Los datos se guardan localmente en IndexedDB del navegador.
5. Usa Configuración > Crear copia de seguridad para exportar tus datos a JSON.

Importante
----------
- No borres los datos del sitio/navegador si quieres conservar el inventario local.
- Cada navegador/perfil mantiene su propia base de datos local.
- La contraseña controla el acceso dentro de esta aplicación local; no sustituye la seguridad de un servidor.
